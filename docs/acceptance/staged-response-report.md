# 分阶段接话与话题恢复验收（2026-11-05）

已实现短首响与主主播回答并行、保留未播稿、真实停顿交接和恢复便签。当前结果不满足“P95 5秒”，也未完成自然共创的语义验收；issue #38 保持开放。

## 实现与边界

四个独立岗位会话不变。主播内部增加事件驱动、最多2并发、4秒超时的一次性首响请求；沿用DSH模型路由、人设和主人规则，不使用固定垫话。DeepSeek主播走非推理口语路径，其他岗位保留原配置。短引用持久化到WAL，解析后按原始输入与epoch校验。

主主播可同时交入后续未播稿，首响生成期间暂不合成或播放；首响失败则释放已准备的回答。直接ack也不能绕过保留顺序。短句按完整句末标点提前提交，逗号不能触发；最终输出以逗号/冒号结束也拒绝。暂停、停止、换epoch会取消，迟到结果不入队。

新首次互动只有音频可播才请求A让位。浏览器按真实时标的停顿窗口交接；实际停止回执原子写入最终已读位置与未读恢复便签。原音频不重播，模型写新台词接回。首次短回应不相互抢断，答案下一段不能打断自己。普通故事便签不能绑定到新问题冒充answer/finish。

`recentHeard`提供最近实际发声的有限前缀，`visualEvidence`提供展示证据。主主播及首响提示明确区分建议与屏幕已完成，故事返回与观众回答分别标记。这些信息和结构校验不能自动证明台词语义正确。
