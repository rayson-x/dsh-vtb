# 舞台团队离线回放

在 `packages/dsh-livestream` 下执行：

```sh
node build.mjs
node scripts/crew-qa/replay.mjs scripts/crew-qa/segments-1031.json
```

只使用 3914；若该端口已经有服务，脚本拒绝接管。密钥只从本副本根目录 `.env` 的 `DEEPSEEK_API_KEY` 读取，开发舞台子进程不继承密钥、不加载 env 文件。模型用 DeepSeek Flash，关闭推理，单次硬超时 4 秒；每段三个岗位并行，各段依次推进舞台状态。没有调用语音合成。

输入为 `{ segments: [{ text, tone? }], topic?: { title, hook?, points? } }`。原始台词里的重音、主持人互动、布景保留；A 原样通过 `/speak`，B 只剥离说明画布和灯光标记，再独立下发合并通过的岗位动作。每段等待说话队列完全清空才发下一段。

`out-2a/plans.json` 包含提案、调用耗时、通过的分镜与丢弃原因。岗位输出 JSON 数组，每项有 `at`、`cue`，可附 `anchor` 原文短语；后者用首次匹配位置校正字位置，原文找不到则丢弃。舞台实际执行依然只认 Unicode 字位置。语法复用 `parseCues` / `drawCue`，再由 reducer 做有状态试算。

开发舞台会把长段拆成短句。脚本复用 `splitForStart`，跟随每句实际 `subtitle.startedAt/ms`，按每字 220ms 加每句 400ms 的舞台估速调度，包含真实换气间隔。截图每 2 秒一张，状态约每 70–100ms 采样；截图调用期间采样会稍有停顿。WebAudio 开启，页面接收一次真实鼠标手势。

输出：

- `out-2a/raw/{A,B}/*.jpg`：全尺寸逐帧截图（验收后清理，仅保留联系表和机器指标）。
- `out-2a/compare-*.jpg`：每六个时间点一张左右联系表，左第一期 B、右第二期 a B。
- `out-2a/capture-{A,B}.json`：实际状态样本、上屏回执与动作时刻（验收后清理，仅保留联系表和机器指标）。
- `out-2a/metrics.{json,md}`：机器指标和表格，含每页淘汰数、每个关键词的对点明细。

指标口径：

- 调用 p50/p90 用最近秩法；按时比例为 HTTP 成功返回且耗时 ≤9秒的调用数 / 总调用数，空分镜也算及时返回；坏输出另计。
- 稀疏画布是主元素（不含 link/group）≤1，连续至少20秒。跨段累计；互动道具计一个主元素，因此这个指标不能直接等同于视觉空白。
- 关键词/数字对点从 `draw` 的内容与正文找最长共有短语（至少2字），以舞台元素实际 `born` 对比对应字的短句时钟。互动不计；没有文字匹配的图形不计。提前预览也会产生偏差，不能把该值全解释成调度抖动。
- 自动淘汰读取实际 `draw.evicted`，按新元素出生去重；显式擦除、主持人翻页/换布景不算挤掉。
- 越道接受数检查实际 `/command` 成功回执，A 的原始标记均属于 host。写错、越道、保护互动、预算和音效避让均在合并前丢弃，原因分别留在分镜记录。
- 灯光全屏预算、每段四个画面动作、主持人同字位置覆盖、迟到动作丢弃、配套音效前后800ms避让放在 `mergeCrew`。reducer 负责车道权限、互动保护、布景菜单/冷却、sound 素材及参数范围。

`--plan-only` 只调用模型生成分镜。`--reuse-plan` 复用保存的模型输出，仍用当前合并层和 reducer 重算分镜，不再调用模型。`--reuse-a` 复用已经完整跑完的 A 采样，仅重放 B；只适用于台词、舞台和 A 分镜没有变化的同一次比较。脚本在正常结束或捕获到回放失败时关闭自己的舞台进程；整套验收结束后调用 `taskSpace("aivtb-crew2 回放").finish({keep:[]})` 结束浏览器空间。


第二期 a 的 DOM 指标：每个浏览器 requestAnimationFrame 绘制帧及每次状态采样运行 `overlap.mjs`，记录任意实体框相交、所有子元素/文字 Range 越界（4px 容差）、实体数超过5。检查器只读取 DOM，不改样式、不停动画；被裁掉的文字也参与测量。指标按实际 requestAnimationFrame 回调计帧，不把100ms状态采样冒充绘制帧；异常帧的完整几何数据另存 frameFailures。

`checker-qa.mjs` 在独立测试页反证检查器能抓到相交和隐藏溢出；`dock-qa.mjs` 通过真实 `/command` 检查挂件收票、保护和揭晓归中。后者与 capture 一样由调用者先设置 `globalThis.QA={root,out,base,space}`，只访问3914。回放的浏览器空间留给后续实测复用，全部结束时只调用一次 `finish()`。

原图按任务要求在验收后清理；清理后复核请用 `--reuse-plan` 完整重放 A/B，不使用依赖旧原图的 `--reuse-a`。最终联系表保存在 out-2a，UI原始测量文本和框汇总也在其中。
