# 黑板与画面轨统一验收

在当前副本 `packages/dsh-livestream` 执行，路径均相对该目录。仅使用控制台 **3825**、舞台 **3925**、大脑 **3945**，不访问原任务端口或空间。

## 准备

1. 产品源码冻结后完成当前构建。宿主的 `.env`、DSH依赖和运行配置由协调者准备；脚本不读取或打印密钥。
2. 起当前构建控制台：`node lib/console.js --port 3825 --stage 3925 --brain 3945`。若环境需要已有代理，可只在该进程启用 `NODE_USE_ENV_PROXY=1` 并将 localhost/127.0.0.1/::1放进NO_PROXY；不改系统代理。
3. `POST http://127.0.0.1:3825/brain/start`。
4. 父协调者使用ego-browser唯一TaskSpace `aivtb 合并验收` 的p1打开 `http://127.0.0.1:3925/`，真实点击解锁声音。之后保持同一文档，不刷新。runner只恢复该空间，检查URL并安装仅观察的音频/首帧探针，不finish。

## 运行与收尾

判定器已修误判的负控可单独复跑：`node scripts/merged-qa/proof-selfcheck.mjs`。它只检查公共QA helper的独立合同，不访问服务或模型，不能替代下面的真实长轮。

撤回选择的真实控制器队列负控：`node scripts/merged-qa/retraction-selfcheck.mjs`。它使用离线语音fixture验证撤同原段未念尾部不会硬切当前发声，不启动服务或模型。

```sh
node scripts/merged-qa/run.mjs 1 2 3
```

必须使用没有任何旧结果/截图JSONL/版本文件的新编号。调试可先跑单轮，最终strict只接受连续三个数字编号。每轮从实际有声主播开口计时，团队开启至少6分钟，再关闭至少1分钟。启动、采集、严格分析任一项失败即非零退出、停止后续轮；三轮产品指纹必须相同。

每轮完成后即可边采后面的轮次，边运行：

```sh
node scripts/merged-qa/contact.mjs 1
node scripts/merged-qa/timeline.mjs 1
```

逐张查看所有联系表，在 `scripts/merged-qa/observations.json` 写 `{ "1": ["第1张联系表全部帧的观察", "第2张..."], ... }`。每轮观察条数必须与该轮联系表jpg数量相同。未完成人工观察不能生成通过报告。

```sh
node scripts/merged-qa/strict.mjs 1 2 3
node scripts/merged-qa/report.mjs 1 2 3
```

总报告写入当前副本 `.deps/tasks/unified-stage-report.md`，未通过连续三轮或缺少逐图记录会拒绝生成通过报告。单轮可重算 `node scripts/merged-qa/analyze.mjs 1`；它不修改run原始JSON，只生成derived测量文件及两个独立判定文件。

截图收成联系表并核对frames.json后，可由协调者删除对应shots目录中的逐帧jpg；保留JSONL、原始run、版本清单、判定、联系表、frames和时间轴。脚本不自动删除证据，不停止脑，不finish父空间，以便同一空间继续跑fx/ui。最终由协调者显式停止大脑、关测试服务并finish。

## 固定门槛与证据

- 黑板每500ms、双轨每200ms读取，同状态压缩为首末时刻与样本数。判定比较覆盖区间之间空洞，并检查起止边界；黑板最多2秒、双轨最多1.5秒。任何轮询/SSE错误均失败，不能靠延长压缩区间掩盖错误。
- 约1分钟动态点题（从当前话题/待讲节目点取方向）、3分钟礼物附言、4.5分钟主人换泛化方向。另从2分钟起在后台寻找真实queued/held未念部分，直至开启期结束前完成一次真实撤回；允许同原段正在发声的头部继续念，仅撤其队列尾部，不注入答案或画面计划。撤回等待不阻塞礼物与主人事件；记录parts、位置、状态和真实removed返回，整轮确实没有可撤部分才失败。三种请求自身回应≤10秒、接话员≤2.5秒；点题≤20秒进单、≤120秒真正展开并点名；礼物在6分钟开启期内兑现关单；换题≤1个旧原段收住、≤30秒新单、旧未讲摘要保留；不重结点、删除有理由、交付素材入架。
- 接话和回应以浏览器实际音频playing推回的有声起点计时；原始SSE时刻单独保留。实际播放覆盖和音频元数据覆盖均≥90%，全程真实声音最长冷场≤6秒。
- 真字音与浏览器首个至少2%可见帧之差±500ms，比例≥90%；至少5个跨≥2原段片段、至少10次成功且实际改变未来计划的edit；已进场组件全部有退场，未念误出0、主持人画面/灯光/布景标记0。旧逐段beforeStart日志已删除，原plan“车道赶上”明确改由这一真实字音准点指标承接，不构造旧日志。
- 团队开启期主元素≤1连续20秒为失败；每5秒DOM相交/溢出为0；连谢0、全屏灯光≤2/分钟、粒子≤3/分钟。关闭一分钟不要求双实体，改检查无pending/active计划、当前主题非空且≤2实体、关闭期无错。
- source指纹覆盖全部src及lib普通文件；工具脚本和会变化的证据不计入产品指纹。采集时不修改产品、不重构建、不改阈值。

媒体事件/联系表不能替代独立听评；展开是否语义兑现要结合报告中的实际原话核对。缺少任何必要证据均失败。
